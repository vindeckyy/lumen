# Architecture decision records

A decision that shaped the code and would be hard to recover from the code alone. Each record
says what was decided, why, and what it costs. The numbered decisions in `docs/design.md` are the
short form; these are the long form.

The naming follows punktfunk's `docs/adr` (MIT OR Apache-2.0, Copyright (c) 2026 unom - Enrico
Bühler).

- `0001-capture-source-contract.md` — what a capture source is and what the host may ask of it.
- `0002-encode-backend-resolution.md` — how the encoder backend is chosen and when the picture is
  resized.
